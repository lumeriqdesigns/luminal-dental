# Lumina Dental & Aesthetic Studio — Website

Serene, high-converting multi-page website for a modern dental practice.

## Pages
- `index.html` — Home (hero, offer, services, comfort features, gallery preview, team, insurance, reviews, CTAs)
- `about.html` — Philosophy, full team profiles, values
- `services.html` — Detailed service descriptions with anchors
- `gallery.html` — Interactive before/after smile gallery
- `insurance.html` — Insurance checker tool + financing options
- `reviews.html` — Verified patient reviews

## Features
- Sticky header + top utility bar
- Interactive multi-step booking modal
- Before/after image sliders
- Insurance provider checker
- Mobile sticky call/book bar
- Medical schema markup
- WCAG-friendly focus states & semantic HTML
- Tailwind CSS + Plus Jakarta Sans / Inter

## Brand
- Colors: Navy `#0A2540`, Teal `#0A9396`, Ice `#F0F7FF`, Mint `#E8F5E9`
- Tone: Warm, reassuring, pristine, modern

## Deploy
Open any HTML file locally or deploy the folder to Vercel / Netlify / any static host.
